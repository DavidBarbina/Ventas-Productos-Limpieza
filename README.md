# Análisis de ventas.

### Desarrollaramos un modelo predictivo para prever las ventas futuras de productos clave como Vanish y Lysol, asegurando que el modelo esté correctamente entrenado y validado.

### Cargamos el conjunto de datos consolidado que contiene las ventas históricas. Seleccionamos la técnica de modelado y dividimos los datos en conjuntos de entrenamiento y prueba para entrenar el modelo.

### Validamos el modelo con sus métricas correspondientes y realizamos un gráfico de las predicciones frente a los datos reales para visualizar el ajuste del modelo.

### En seguida, realizamos ajustes al modelo para mejorar su precisión y documentamos los cambios realizados y su impacto en el rendimiento del modelo.

### Por último, utilizamos el modelo optimizado para predecir las ventas futuras para los próximos meses y presentamos las predicciones.
